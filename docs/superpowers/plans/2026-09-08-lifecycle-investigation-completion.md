## Implementation Decisions

The replacement journal uses `lifecycle_investigation_*` tables, version 2, with
target snapshots rather than a legacy case FK. Installation is explicit and
transactional; existing v1 Web journals remain immutable and readable. A new
investigation creates no SEC/provider case. A human-confirmed action creates a
small `lifecycle_investigation` source anchor tied to the real run, solely for
the existing assessment/transition/receipt writer. It is neither a fabricated
filing nor a new legacy queue entry. Actual watchlist and identity mutations stay
in the existing atomic writer with its portfolio, stale-state and reverse guards.

The configurable defaults are 24 model submissions, 24 native Web actions,
32 source reads, 96 HTTP attempts, 20 local queries, 1,800 seconds total and
600 seconds per model submission. They replace the failed two-call workflow:
one search plus one analysis could not follow an original reference or repair
a source-bound finding. The defaults allow several such follow-ups without
requiring any quota to be filled. A no-progress stop still bounds repeated work.
Limits are one run-wide ledger, never reset by a correction. API output defaults
to 8,192 tokens, subject to the exact model capability; OAuth output remains
provider-controlled. Runtime settings are independent of general AI Research.
Source transport/decoded limits remain 32/128 MiB. Retained source text has a
separate cumulative byte budget; it is not a claim to enforce Python process RSS.

The host supplies readonly typed local search/read, public search/read and
passage inspection. Every model chooses a next action or a closed final finding;
the host executes only that action and records it. Completed but malformed or
ungrounded candidates may be corrected within the same ledger. Transport,
auth, quota, identity or cancellation failures do not retry or fall back.

Captured passage IDs bind exact offsets and hashes. Definition and event
passages from the same source may establish common-stock identity together;
a debt event cannot borrow a stock identity from another paragraph. Sources,
observations and material gaps remain visible in the confirmation packet.
SEC is optional, below local news and targeted public notices in acquisition
priority, not mandatory authority. Announced acquisitions never stop collection.

Legacy retirement disables only lifecycle SEC intake and its old queue
projection. SEC financials, SA/news collection, prices and healthy tracking stay
unchanged. Disposal is a separately executable, digest-bound reviewed manifest;
actual action dependencies are retained. No blanket production cleanup follows
from changing the product screen.
