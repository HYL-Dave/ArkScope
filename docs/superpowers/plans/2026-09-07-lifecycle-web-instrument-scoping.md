## Acceptance

Transport success and an actionable finding are different. A successful canary
requires exact auth/model witnesses, actual search/read/analysis, and reopened
journal/projection agreement. An action-ready result additionally needs
common-stock-specific listing evidence, a supported event date and no essential
identity/continuation/active-OTC contradiction. Debt-only or acquisition-only
evidence remains an unresolved finding, not permission to remove TA or a request
for the user to redo the investigation.
