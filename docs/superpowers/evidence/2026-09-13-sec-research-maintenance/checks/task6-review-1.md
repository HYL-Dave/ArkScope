# Issues

## Important (Should Fix)

1. **Protect the profile database's SQLite sidecars from operator outputs.** [maintenance.py:360](/tmp/arkscope-research-output-boundary/src/sec_research/maintenance.py:360) rejects only the market DB and its sidecars. The profile path returned by `_profile_admission` is not included in this check. For an existing separate rollback-journal profile with no current journal, a valid schema apply can therefore accept `backup_path=<profile-path>-journal`; [schema_admin.py:35](/tmp/arkscope-research-output-boundary/src/sec_research/schema_admin.py:35) admits that path, and raw backup creates a directory there. This occupies the profile's journal pathname and prevents subsequent normal profile transactions from creating their journal. Preview/receipt JSON can likewise occupy the profile's reserved sidecar names, so those artifacts are not isolated from SQLite lifecycle operations. Protect the observed profile DB and its `-journal`, `-wal`, and `-shm` names for every preview/receipt/backup destination before output creation, preserving observational/query-only admission. Add a separate-profile sidecar positive protection control; the existing market-journal test does not cover this input.

2. **Keep failure-audit publication inside the already-acquired exclusive SEC lease.** The outer exception handlers at [maintenance.py:483](/tmp/arkscope-research-output-boundary/src/sec_research/maintenance.py:483) and [schema_admin.py:95](/tmp/arkscope-research-output-boundary/src/sec_research/schema_admin.py:95) run only after their `with research_operation(..., exclusive=True)` blocks unwind. `_finish_failure` then calls `audit.write` at [maintenance.py:385](/tmp/arkscope-research-output-boundary/src/sec_research/maintenance.py:385) without the lease. Thus an unlink failure, post-backup stale check, or rolled-back schema mutation permits another SEC reader/producer/administrator to enter before the blocked receipt is durably published. This violates the explicit audit-under-exclusive-lease ruling and allows the recorded resource/accounting state to race subsequent operations. Finalize failures inside the original SEC lease after the short market transaction has unwound; do not release and reacquire the lease. Add a failure-audit barrier asserting that a different-owner SEC operation is excluded while an unrelated market write remains possible.
