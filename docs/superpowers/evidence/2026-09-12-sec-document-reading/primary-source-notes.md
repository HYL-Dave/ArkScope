# Public Technical Documentation

These were documentation-only browser reads; no issuer filing, provider API,
credentials or production database was acquired.

- SEC Accessing EDGAR Data:
  https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data
  Actual accession directories support index.json; accession prefix may identify
  a filing agent rather than the issuer.
- SEC APIs:
  https://www.sec.gov/search-filings/edgar-application-programming-interfaces
  Submissions metadata and extracted XBRL/companyfacts are separate source shapes.
- XBRL International, Inline XBRL Part1, Recommendation2013-11-18, sections2.3/2.4:
  https://www.xbrl.org/specification/inlinexbrl-part1/rec-2013-11-18/inlinexbrl-part1-rec-2013-11-18.html
  Namespace1.1 is http://www.xbrl.org/2013/inlineXBRL; its table also identifies
  namespace1.0 as http://www.xbrl.org/2008/inlineXBRL. Prefix names in examples
  do not replace namespace identity. This supports Task1 review I1 correction.
