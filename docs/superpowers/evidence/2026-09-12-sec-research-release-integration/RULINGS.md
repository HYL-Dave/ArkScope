# Integration Rulings

These are the controller's recorded scope/interface rulings, in ledger order.
Earlier approved source work is included for continuity; the current publication
repair and schedule continuation begins at item8. This file is not permission
to operate on the user's databases or activate a runtime.

1. **Independent C09 deletion before later SEC tasks.** The unused provider
   leaves changed neither storage nor SEC execution and the user requested
   cleanup. Any live caller would stop deletion. Cost if wrong: a missing
   provider capability; concrete caller scans and retained provider tests own it.
2. **Operation protection before maintenance.** Preserve Task5-before-Task6:
   writer exclusion alone cannot protect readers or citation publication.
   Cost if wrong: unnecessary lock overhead; operation-lifetime and lock-order
   tests must prove acquisition and release without deadlock.
3. **No inferred SQLite activation.** Continue approved source implementation,
   not the actual runtime switch; deployment selectors, package and stopped-
   writer backup window require admission. Cost: activation remains separate.
4. **Absent Research namespace differs from partial schema.** A valid observed
   profile with the entire lazy Research namespace absent is observed empty;
   missing profile or partial/corrupt schema blocks maintenance. Cost if wrong:
   loss of references, guarded by absent/partial/corrupt positive and negative
   controls, without weakening the installed-root iterator.
5. **Keep pre-existing i18next diagnostic noise.** Treat it as nonblocking,
   preserve raw output and do not change product logging or suppress unrelated
   test warnings. Cost: larger evidence and noisier logs, not hidden failures.
6. **Unknown-schema backup is not DROP authority.** An exact-digest-approved
   apply may create its explicitly requested raw backup, but remains blocked at
   `backed_up` with `inspect_raw_backup`; never reset a known subset. Cost if
   wrong: disclosed backup I/O/space, not source deletion.
7. **Short global market writer locks.** Keep SEC-exclusive coordination while
   moving full reference/file verification, hashing, backup and unlink work
   outside the global market writer lock. Use short mutation/reconciliation
   transactions and fresh checks. Cost if wrong: races or ingestion blocking;
   deterministic different-writer controls and DB-phase exclusion own it.
8. **Repair only a proven redundant publication alias.** Writer recovery first
   commits accounting, then removes only the canonical same-inode staging alias
   after hash and identity rechecks. Admin inventory remains strict. Cost if
   wrong: unlink/accounting safety, covered by foreign links, replacement,
   corruption and interrupted-operation controls.
9. **Reuse scheduler exclusion.** Existing source flock/backpressure owns batch
    scheduling; Task5 protects the complete SEC operation/citation lifetime.
    Do not add another general job lock. Cost if wrong: concurrency or ingestion
    regressions, covered alongside existing news/macro scheduler controls.
10. **Separate recent and full-history acquisition scope.** Scheduled recent
    receipts cannot resume/replace full-history continuation, while committed
    recent data remains visible to unpinned readers with truthful coverage.
    Pinned receipt identity remains fixed. Cost if wrong: stale or misleading
    research data; query, cursor, document, citation and export tests own it.
11. **Do not expand the shared job audit enum.** SEC partial remains `partial`
    in the result and scheduler state, with a `failed` audit and an explicit SEC
    partial reason, following existing macro mapping. Cost if wrong: misleading
    status; actual adapter, durable state and audit-row tests must agree.
12. **Observed symbol admission is not SEC issuer parsing.** Preserve bounded
    normalized universe members such as `BRK B`; record SEC-unresolvable members
    explicitly and keep other issuers eligible. Do not alias symbols or relax
    URL/issuer parsing. Cost if wrong: one symbol can disable all collection or
    be mapped incorrectly; mixed-membership and exact-hidden-veto controls own it.
13. **Fix all three concrete Task7 review defects.** Select the matching storage
    gap, bind resolution to the captured map observation and require complete
    terminal membership accounting. These repair existing contracts, not add
    features. Cost if missed: misleading terminal status or issuer provenance.
14. **Operator maintenance stays CLI/core-only.** The combined workflow uses
    real preview/approval/apply on generated stores; browser checks cover actual
    Research/Settings/config/schedule controls. Do not invent a destructive HTTP
    or model surface to satisfy loose workflow wording. Cost if wrong: a missing
    operator UI remains explicit, rather than unplanned remote exposure.
15. **Repair delegated SEC execution without changing routing.** An admitted
    Anthropic parent/child composition must invoke its SEC tools successfully.
    Preserve configured models/auth/effort and required inventory; async or owned
    worker dispatch must retain cancellation/join and operation/output lifetime.
    Cost if wrong: stranded work, authority drift or prematurely released
    reference protection; a real parent/child regression and cancellation owner
    are required before the final gate.

16. **Retain actual delegated SEC completions.** Use invocation-local trusted
    observation into the existing native parent event producers; keep actual
    SEC names and unchanged citation validators, schemas, delegate results and
    storage. Drain admitted completions on failure/cancel and prevent late or
    cross-run admission. Do not introduce OAuth delegation or nested tracing.
    Cost if wrong: trace collisions, missing references or early protection
    release; actual retention/isolation/cancellation tests own the boundary.

17. **Keep live sync entry, remove test-only private wrappers.** Public synchronous
    delegation stays supported; each child provider has one actual async owner.
    Move direct helper tests, including Fable runtime collateral, to that owner
    without dropping their assertions. Cost if wrong: unsupported external private
    callers need adaptation; live repository callers and sync/Fable tests remain
    the contract, not hypothetical private-API compatibility.

18. **Do not accept a known blocking caller regression.** Final re-review closes
    the three named repairs but finds synchronous Anthropic model I/O newly on
    the OpenAI parent's event loop. Keep release acceptance and merge blocked;
    propose a separately scoped awaitable child client preserving captured auth
    and cancellation ownership. Do not hide a second fix wave or call collected
    tests passed. Cost: delayed acceptance, not a knowingly shipped stall. The
    direction was put to the user; no client-factory change is included here.
